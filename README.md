# Jacob Pixel Animation

A no-paid-AI, programmatic 30-second vertical pixel-art animation inspired by Genesis 32:22–32.

## Output
- MP4, 540 × 960 (9:16)
- 30 seconds, 12 frames per second
- Original synthesized ambient pad (no third-party music)
- Captions and Scripture reference

## Render
Run the GitHub Actions workflow named **Render Jacob Pixel Animation** manually from the Actions tab. The MP4 is uploaded as a workflow artifact for 7 days.

This project uses Python, Pillow and FFmpeg. GitHub-hosted standard runners are free for public repositories under GitHub's published Actions policy.
